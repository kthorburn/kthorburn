## Problems I Had, and What I Did About Them

### 🔔 "My AI agent has been waiting for me to click Run for 40 minutes."
**[Cursor Approval Alert](https://github.com/kthorburn/Cursor-Screenviewer-Notifications)**: a repeating chime whenever Cursor's Agent is waiting on an Allow or Run approval. It's built for workplaces where auto-run is off and a human has to approve every command. It never clicks anything for you and never phones home. You can use a multi-monitor screen watcher (pure-NumPy template matching) or a Cursor hooks integration with no dependencies.

`Python` `NumPy` `Computer Vision` `Cursor Hooks`

### 🚫 "I opened YouTube to watch one video and lost an hour to Shorts."
**[Shorts Blocker](https://github.com/kthorburn/shorts-blocker)**: a Chrome extension that hard-blocks Shorts, Reels, TikTok, Reddit video, and Spotlight. The rest of each site keeps working. You can toggle each platform separately, and it keeps a running count of everything it blocked.

`JavaScript` `Chrome Extension` `Manifest V3`

### 🚦 "The instructions say: ON 8 seconds, OFF 2 seconds, repeat 5 times, then ON."
**[Cync Reset Stoplight](https://github.com/kthorburn/cync-reset-stoplight)**: a stoplight timer for factory-resetting Cync / C by GE smart bulbs. Green means flip it on, red means off, and yellow means get ready. No more counting Mississippis at a light switch. [Try it in your browser →](https://kthorburn.github.io/cync-reset-stoplight/)

`HTML` `JavaScript` `Python` `GitHub Pages`

### 📈 "What have S&P 500 companies actually been talking about for the last ten years?"
**[Earnings Call Theme Explorer](https://github.com/kthorburn/CSE6242_Final_Project)**: LDA topic modeling, hierarchical clustering, and LLM relabeling across a decade of earnings call transcripts, explorable in Tableau and a custom D3.js circle-packing chart. *Georgia Tech CSE 6242 team project.*

`Python` `NLP` `LDA` `LLMs` `D3.js` `Tableau`
